# Catstella · 用量独立挂件设计对照原型（Quota Side Widget Study）

这是为 **Catstella 桌宠** 设计的「耐力计式」用量独立挂件交互原型。它脱离以前单独浮窗 Demo 的方案，直接跟随在桌宠身旁空旷一侧，参考塞尔达 / 原神耐力条的即时伴随手感，使用星语与霓音现有美术资产与 App 主题令牌进行原创图形化设计。

> 本原型完全隔离于 `D:/Catstella/prototypes/quota-side-widget-study/` 目录内，零外部构建依赖，不修改主工程运行代码。

---

## 一、运行方法

### 方式 1：浏览器直接打开（最快捷）
直接在浏览器（Edge / Chrome / Firefox）中打开：
```text
D:\Catstella\prototypes\quota-side-widget-study\index.html
```
（全部相对路径均指向 `../../Antigravity-Cat-Widget/assets/...`，`file://` 协议下即可正常加载角色帧图与特效资源。）

### 方式 2：本地静态服务启动
在仓库根目录 `D:\Catstella` 运行任意静态服务器：
```powershell
npx serve .
# 或 Python
python -m http.server 4173
```
然后访问 `http://localhost:4173/prototypes/quota-side-widget-study/`。

## 二、三版视觉方案与选型建议

| 方案 | 视觉意象 | 横向占位（默认 220px 缩放） | 双周期可读性 (`5h` + `1w`) | 适用场景建议 |
| :--- | :--- | :--- | :--- | :--- |
| **A. 星晶双环 (`ring`)** | 塞尔达双圈耐力轮 + 中心四芒星晶 | 约 `60 × 60 px` | ★★★★★（外环 5h + 内环 1w，独立配色一目了然） | 适合偏好正圆仪表盘、桌面留白充裕的宽屏玩家作为备选样式 |
| **B. 星辉能量柱 (`bar`)** | 四芒星冠双轨水晶柱（主柱 + 细伴随条） | 约 `26 × 82 px` | ★★★★☆（并排竖条 + 25/50/75% 刻度） | **空间紧张时首选**：横向仅 ~26px，在 380px 窄分屏或 300px 大缩放贴边下依旧轻盈不遮挡 |
| **C. 星轨弦月弧 (`arc`)** | 原神弧形耐力条 + 镜像贴合耳侧弧光 | 约 `40 × 94 px` | ★★★★☆（外弦月主弧 5h + 内伴随细弧 1w + 顶端星晶） | **默认推荐**：左右换边自动水平镜像贴合猫猫头部曲线，既有原神级沉浸贴身感，占位又比圆环收窄约 1/3 |

### 推荐生产接入策略
1. **默认形态采用 `arc`（星轨弦月弧）**：视觉与星语发卡/霓音耳灯的四芒星晶最一致，随左右侧镜像包裹角色轮廓，完全不打扰桌面主体。
2. **极窄宿主/大缩放自动降级为 `bar` 或 `corner-avoid`**：当宿主窗口可用侧边净空低于阈值（如窄分屏下桌宠放大到 `260–300px`），既可使用本原型实现的 `corner-avoid` 肩角退避，也可在设置中将紧凑模式自动切换为 ~26px 宽的 `bar`。

## 三、交互与边界验证清单

原型内置了真实可操作的桌面舞台与验证控制区，可直接测试以下所有生产高频场景：

1. **自动选边、防抖滞回与内向面部朝向 (`computeSidePlacement` / `facingAt`)**
   - 点击顶部「贴左」「居中」「贴右」「贴顶角」，或直接拖动桌宠横跨舞台中心。
   - 当桌宠贴近左缘时挂件自动切到右侧、桌宠面朝右（水平镜像翻转 `.agy-face`）；贴近右缘时挂件切到左侧、桌宠面朝左（保留原画微左朝向），始终面向舞台内侧，顶部遥测条同步显示 `朝向: 面向左 / 面向右`。
   - 经过中心线时带有滞回死区（常规 `18px`、拖拽中 `44px`），杜绝跨中线瞬间反复闪烁。
2. **挂件距离与大小微调 (`SIDE_DISTANCE_GAPS` / `SIDE_SIZE_FACTORS`)**
   - 左侧控制区提供克制范围内的双微调控件：
     - **挂件距离**（`#distance-group`）：`紧凑`（`2px` 基准间距）/ `普通`（`10px`）/ `松弛`（`20px`），随桌宠缩放比例同步换算，贴右测距下即便是「紧凑」档也不会与角色外框右侧的 `.widget-tools` 重叠。
     - **挂件大小**（`#size-group`）：`小`（`0.86×`）/ `中`（`1.00×`）/ `大`（`1.14×`），舞台即时生效并同步预览到下方三版静态对照卡片。
3. **窄屏 / 不同缩放避让 (`140 / 180 / 220 / 260 / 300`)**
   - 切换舞台背景为「窄屏 380px」并把桌宠缩放到 `300`，挂件会依次经历 `side-normal` → `side-tucked` → `corner-avoid`（抬升到外侧肩角），始终留在视口内且不遮挡猫猫面部与右侧 `.widget-tools`（`•••` / `✦`）。
3. **悬停与键盘聚焦详情浮层（符合 WCAG 1.4.13）**
   - 鼠标悬停或按 `Tab` 聚焦挂件时，按屏幕剩余空间智能朝向展开浮层，展示模型名称、思考强度、5h / 1w 精确百分比与重置时间，以及 `演示` 来源标记。
   - 鼠标移入浮层本身不会关闭；按 `Esc` 可直接关闭浮层且不抢夺焦点。
4. **气泡唤醒、自动碎碎念与步骤卡避让**
   - 点击桌宠或 `.widget-tools` 唤醒完整气泡时，旁侧挂件立即解除交互热区（`pointer-events: none` / `inert`）并顺滑渐隐；收起气泡或 6.5s 自动关闭后延迟 `55ms` 渐显回归。
   - 点击「模拟自动碎碎念」或「模拟步骤提示卡」可验证临时气泡期间的同源避让与复原。
   - 点击「快速来回切压力测」可自动连续高速切换气泡、碎碎念与左右贴边，验证无闪烁、无半透明残留与点击穿透。
5. **拖拽期间与穿透保护**
   - 拖拽桌宠时，挂件进入轻量半透明伴随（`opacity: 0.8`、`pointer-events: none`），外层坐标同步 1:1 紧跟不拖沓；开启「显示热区与避让边界」与「模拟鼠标穿透」，点击舞台左上角「背景穿透测试区」可验证零遮挡与零误拦截。
6. **耐力消耗拖尾 & 额度档位（遵循 `quota-spec.json`）**
   - 提供 `充沛 84%`、`稳健 52%`、`偏低 24%`、`告急 8%`、`周限紧 76/9%`、`耗尽 0%`、`未读取 —` 七个档位与「模拟对话消耗 -10%」按钮：数值下降时主进度立即扣减，同时保留一截半透明「残影拖尾」平滑回落；`0%` 与 `—`（斜纹轨道、无 `aria-valuenow`）严格区分。
7. **尊重减少动态效果 (`reducedMotion` & `prefers-reduced-motion`)**
   - 开启「减少动态效果」后，关闭呼吸动画、星晶微光、告警呼吸与弹性过渡，状态切换仍保证最终不透明度与坐标准确落位。

## 四、后续生产接入建议（对应 Catstella 主仓库模块）

1. **窗口与坐标层（`Antigravity-Cat-Widget/src/domain/host-visibility.cjs` & `src/main/index.cjs`）**
   - 若将挂件绘制在同一透明悬浮窗内，需把 `widgetLayout` 左右预留或偏移逻辑同步考虑挂件宽度（如 `arc` 约 `+48px`、`bar` 约 `+34px`），并确保 `characterPlacement` 在 `dockSide === "left" | "right"` 时让视觉区紧贴边缘而挂件自然落向内侧。
   - 可直接复用本原型中的 `computeSidePlacement()` 逻辑，把 `bottomReserved` 设为普通 `edgeMargin`（如 `8px`）。
2. **点击穿透热区（`Antigravity-Cat-Widget/src/domain/mouse-routing.cjs`）**
   - 当前 `MouseRouting` 通过 `document.elementFromPoint(x, y)?.closest('.interactive')` 决定 Windows 鼠标穿透。
   - 生产接入时，当挂件处于 `suppressed`（主气泡已展开 / 碎碎念 / 步骤提示）、`dragging` 或 `clickThrough` 时，务必像本原型一样同时确保触发器 `pointer-events: none` 或动态移除 `.interactive` 类，防止渐变退场中途拦截宿主窗口点击。
3. **主气泡与碎碎念联动（`Antigravity-Cat-Widget/src/renderer/renderer.cjs`）**
   - 用统一衍生状态 `const mainBubbleVisible = !closed && s.bubbleOn;`（其天然覆盖点击打开的气泡、步骤 `turnCost` 临时卡和 `ambientChatter` 自动碎碎念）驱动挂件的 `data-suppressed` 状态即可，无需额外维护多套开关。
4. **主题与无障碍对齐（`Antigravity-Cat-Widget/assets/ui/bubbles/quota-spec.json` & `widget.css`）**
   - 复用 `violet / pink / ocean / onyx` 主题令牌与 `reducedMotion` 设置标记（`data-reduced-motion`），并保留低额/告急/未知的非纯色图标/斜纹区分。
5. **双计量口径切换（AGY 剩余 % / Web 端正向已用 %）**
   - 顶部提供「剩余 (AGY)」与「已用 (Web 正向)」两档模式开关：
     - **剩余模式 (`remaining`)**：对齐 Antigravity 宿主语义，`100% → 0%` 倒数泄能，点击消耗 `-10%` 出现耐力条金色拖尾；
     - **已用模式 (`used`)**：对齐 Gemini Web 端常见「已用 XX%」统计习惯，`0% → 100%` 正向递增充能（默认仅低占比填充，点击 `+10%` 会展示增能推进高亮），风险告警仍忠实对应底层余量（如 `≥ 70% 已用` 为偏低警告、`≥ 90% 已用` 进入告急态、`100% 打满` 呈满红感叹号，且「未读取 `—`」与「已用 `0%`」严格区分）。
6. **面部朝向与挂件微调配置**
   - 角色面部朝向默认随贴边反转（靠右侧屏幕面朝左，靠左侧屏幕面朝右），并在设置中预留克制档位的 `sideDistance`（`compact | normal | relaxed`）与 `sideSize`（`sm | md | lg`）微调项，供用户按屏幕分辨率微调贴合度。
