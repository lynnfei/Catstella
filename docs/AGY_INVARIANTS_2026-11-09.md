# AGY 轮播与回复透明效果修复

后续补丁恢复旧版圆角装饰并优化滑块与宿主外观更新，最新部署见 [圆角与性能修复](AGY_ROUNDED_PERF_2026-11-09.md)。下文保留此前轮播/透明度修复与重载记录。

2026-11-09 用户恢复额度后授权继续修复。此记录取代先前将“已加载新皮肤”当作完整轮播修复依据的结论。

## 已确认的问题

1. **首次注入存在异步重入。** 旧引擎在图片解码后才登记实例；同时到达的初始化可各自留下观察器和焦点监听。真实 AGY 发现 5 份同名皮肤样式、5 个本项目焦点监听。隔离重放热更新前的引擎，并发初始化可复现 2 份样式；仅删除重复 DOM 不能清理这些闭包。
2. **AI 阅读背景存在多套规则。** 不同回复分别使用 markdown 根、prose 或 leading/select-text 容器；旧的近实色玻璃渐变、清底标记和段落补底竞争，嵌套结构也会叠底。延后扫描原生包装层会造成首帧效果变化。
3. **壁纸有两套选择依据。** 已迁移配置中，旧 `wallpaperFile` 仍可能压过新 ID；部分 ID-only 保存也未同步文件路径。展示、重启及同步读取需要同一规则。
4. **迟到解码缺少完整失效处理。** 切回已显示图片的快捷路径没有取消另一张仍在解码的请求；后者完成后仍可能覆盖最新选择。另一方面，开始解码不应废弃尚在正常结束的当前过渡。
5. **自动轮播漏发快照。** 主进程保存和宿主更新后没有广播当前选择，设置页会继续显示旧快照。失焦动画的异步暂停还可能多走一帧。

这些是可复现的故障来源；不据此断言已覆盖用户所有历史环境或每个未来 AGY DOM 变化。

## 修复约束

- 初次解码期间只允许一个初始化过程，合并到最新配置；每个新实例持有自己的有效身份，失去身份后停止并清理。迟到的旧实例卸载只能清理自己的节点，不能删除新实例。
- 正常保存、启动、桥接展示与图库高亮以有效壁纸 ID 为准，ID 与文件路径成对保存。只有明确的旧版迁移、文件选择操作允许由文件解析 ID。
- 已失效解码不能回写；有效的当前过渡由图层身份管理。失焦同步冻结当前动画时间，后台只记最新目标，回前台继续过渡，不闪回旧图。
- 自动轮播按现有全局间隔和顺序运行，同时广播新快照。生产间隔仍为分钟级；加速计时只允许在经过路径验证的临时隔离测试配置中使用。
- 用户气泡与 AI 背景独立。未设置时用户背景 100%，AI 透明模式 0%、玻璃模式 22%；显式设置保留。设置主题工坊加入 AI 背景不透明度，旧本地主题不覆盖新增偏好。
- 多种 AI 根容器使用同一背景；嵌套根与段落不再叠底。语义包装层通过 CSS 在首帧清底，扫描器作为补充。代码区、编辑器、工具卡片和文字整体透明度保留各自用途。
