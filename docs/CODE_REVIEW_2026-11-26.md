# Tauri 设置与耐力条初审 · 2026-11-26

范围：当前 `codex/tauri-fixes` 工作树中的耐力条、Tauri 设置页、前端暂存流程和本机更新入口。结合本轮 Firefox 音频修复的既有回归，保留用户的未提交修改。本记录不是全仓库安全审计结论，供下周基米继续复核。

## 本轮已处理

- **耐力条预览分叉。** `src-tauri/settings-hud/settings.js` 独立拼接三套 SVG，与 `Antigravity-Cat-Widget/src/renderer/side-quota.js` 的真实几何、警告状态和主题发生漂移。删除重复构建器，设置预览复用 `updateGaugeMount`，同样式更新保留现有 SVG 节点。
- **预览数据来源分叉。** 设置页自行判断 AGY/Web，没有复用桌宠按前台窗口选择数据源、识别编排器的规则。改为共享 `resolveSideQuotaMetrics`，输入保持剩余额度，展示层只换算一次已用模式。
- **预览隐藏后恢复。** 容器被清空但保留 `mountedVariant` 时，相同样式无法重建。共享挂载器同时检查真实节点是否存在，隐藏/显示恢复通过。
- **装饰滤镜。** 星徽原先循环动画 `filter:brightness()`，Omnitrix 额外叠加发光滤镜。本轮改为轻量透明度呼吸、收敛静态阴影；减少动态偏好继续生效。未把视觉变化宣称为全局性能测量。

## 留待复核

1. **已修复（原 P2）· 商店状态刷新重建卡片。** 用户追加授权后，`tools/verify-hud-store.cjs` 已在旧构建复现：连续额度快照会替换卡片并丢失按钮焦点。设置页现按目录可见字段、分类与搜索内容决定是否重建；安装/使用状态只原地修改标签与按钮。相同目录刷新保留节点，目录内容实际变化后尽量恢复相同卡片/操作的焦点及滚动位置，Banner 也按内容变化更新。源码和暂存目录回归均通过：100 次额度快照保留按钮身份、焦点、滚动；安装/使用标签、相同及变更目录刷新、搜索、详情和单次应用调用通过。下午交由 Astra 复核，不代表商店整体 UX 和帧率已完整验收。
2. **P2 · Tauri 试听未播放。** 设置页 `#audition` 仅调用 `void api.audio("release")`；`tauri-widget-api.js` 的 `audio` 返回 `invoke("widget_audio")`，Rust 命令仅返回音频 URL 和音量元数据。桌宠渲染器会另外创建播放器并调用 `play()`，设置页缺少这一步。建议补上试听播放器和静音/连续试听取消逻辑，再用真实 WebView2 验证。
3. **构建维护风险。** `prepare-frontend.cjs` 依赖多处精确字符串替换来改造共享 Electron 代码（包括 Argon/BYOK 和称谓）。当前有 `replaceRequired` 强制失败，避免悄悄打出错误文件；后续共享源改动仍容易让暂存失败。建议逐步改为显式适配入口，保持本轮的失败门禁，不能直接删掉检查。
