# Web 输入增高覆盖边栏 · 2026-11-10

用户反馈输入长消息时，地图等边栏信息被顶掉。隔离复现确认：地图位置没有变化，是渐隐层越界绘制，将边栏下方内容盖住。

## 根因和修复

原 `fade.js` 使用整个壁纸平面作为渐隐层范围；壁纸包含聊天与辅助边栏。输入框增高时，渐隐起点向上移动，因此地图也进入覆盖区。

修复保留全尺寸壁纸平面以维持图案和透明度对齐，再根据聊天滚动栏的可见左右边界裁切渐隐绘制范围。边界变化纳入几何签名；继续通过已有 ResizeObserver 更新，不添加滚动／鼠标监听，不改变地图或聊天原生布局。

## 验证

- 修改前，新增分栏像素测试稳定失败：输入框由 80px 增高至 280px 后，地图探测点被渐隐覆盖。
- 修改后，地图像素和边框位置保持，内嵌地图按钮可点击；聊天边距仍渐隐，不将范围缩成输入框宽度。
- 输入容器平移／缩放、分栏宽度变化、关闭边栏恢复整栏渐隐均通过。
- 分栏布局使用自身的底图作为像素参考，避免把切换布局时底层合成的变化误计为渐隐误差。
- 原壁纸对齐／透明度、输入层叠与交互、缩放宿主、增高响应和清理检查通过；源代码和实际 `dist/chromium` 产物均验过。
- 皮肤浏览器回归和 23 项 Web 单测通过；固定外观门禁通过，覆盖 AGY 角色透明度、轮播和 Web 底部渐隐。

新增场景同时进入扩展 `test/fade-browser.cjs` 与固定门禁 `tools/verify-web-footer.cjs`。门禁保留“聊天底部遮挡”和“辅助边栏不受影响”两项约束，不能以关闭渐隐来解决覆盖。
